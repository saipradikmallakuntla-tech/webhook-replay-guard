A simulation, not an operational guard

No webhook endpoint, HMAC/signature verification, secret handling, authentication, durable store, distributed locking or exactly-once guarantee is provided. IDs are assumed trustworthy only for this synthetic model. Real defenses require verified signatures, safe key scoping, atomic durable deduplication, monitoring and a threat review.

All timestamps are numeric Unix seconds. Events are processed by receivedAt, with original row order breaking ties. Age is receivedAt + receiver clock offset − signedAt. Both timestamp-window boundaries are inclusive. Deduplication expires exactly at first accepted arrival + TTL; rejected duplicates do not extend it. Freshness is checked before deduplication. A new run starts with an empty cache.

Inputs stay in the tab. No network probes, storage, telemetry, uploads or APIs. Reports omit event IDs and payloads. Maximum 500 events and 100,000 text code units.
